# Link-building outreach: DRAFTS ONLY (not sent)

Review and edit before anything goes out. Nothing here has been sent to anyone. Prospects are in
`docs/link-building-prospects-2026-10-02.md`.

Rules that apply to every message:
1. Replace every `[PLACEHOLDER]`. Never send a template with one left in.
2. Only claim what is true. Use real facts from our own articles; do not add numbers, client names or
   results that are not already published on byteandbook.com.
3. Never offer money, link swaps or reciprocal links. Never ask for a specific anchor text.
4. Keep it short. Follow each site's own submission instructions exactly (some want a form, some want a
   subject line, some want an outline first). If their page says "no promotional content", write the
   piece that way.
5. Maximum two follow-ups, a week or more apart. If they say no, say thanks and stop.
6. Sender: use a real team member's name and address, as agreed by the business. Do not invent a title.

SECTION OF THEIR SITE YOU CHECKED].

## Template 2: broken-link notice

Lead with the useful fact. The replacement is optional and must be honest about what it is.

**Subject:** A dead link on "[THEIR PAGE TITLE]"

Hi [NAME or "team"],

While reading "[THEIR PAGE TITLE]" ([THEIR PAGE URL]) I noticed that the link to **[DEAD LINK DESCRIPTION,
e.g. "the Skype brand book"]** no longer works:

[DEAD URL] : [RESULT, e.g. "returns a 404" or "the server does not respond"]

It appears in the section "[SECTION HEADING]", next to the text "[A FEW WORDS OF THE SURROUNDING TEXT]".

In case it helps, here are two options:
- Remove or replace it with a working copy, if you have one. [IF TRUE: "The Internet Archive may hold an
  older copy: [ARCHIVE URL]". Only include this after you have opened the archive link and confirmed it.]
- If you would like an additional resource on [WHAT THE SECTION IS ABOUT], we published
  [OUR ARTICLE TITLE] ([OUR ARTICLE URL]). It is a how-to rather than an example guide, so it only fits
  if you want a "what to include" reference alongside your examples. Entirely your call.

Thanks for keeping the page up to date.

[SENDER NAME]
[ROLE, only if approved] at ByteAndBook

### Before sending a broken-link notice, check
- [ ] The link is still dead today (open it; try a second network).
- [ ] The page is still live and still contains the link.
- [ ] Our replacement is a real match for what the dead link covered. If not, send the notice without
      the replacement, or do not send it.
- [ ] You have the right contact route (the page's own contact link or editor address).

### Prospect-specific notes
All current broken-link prospects are brand-guide examples (see the prospects doc, section B). Our brand
article is a how-to, so for these five pages use the version of the template that **leads with the dead
link and treats our article as optional**, as written above.

## Reply handling

| They say | You do |
|---|---|
| Yes, send a draft | Write to their guidelines. Disclose nothing misleading. Send on time. |
| Yes, but they want a paid or sponsored placement | Decline politely. Paid links are outside our method. |
| They ask for a link to a service page | Offer the bio link only, or a natural in-text reference to a relevant article. |
| No | Thank them. Do not follow up. |
| No reply after two follow-ups | Close the row in the tracker. |
