# Link-building: first-batch prospect list (2026-10-02)

Method (decided by the owner): **guest posting + broken-link building.** Not directories, partner
cross-links or digital PR.

**How this list was made.** Search queries for "write for us" / contributor pages in four niches, then a
live check of each page, then a script that fetched resource and roundup pages and tested their outbound
links. Everything below was seen on the date above. Nothing has been contacted. No names or personal
contacts are listed: use the contact route on each page and confirm it again before sending.

**Ground rules for every pitch** (see `docs/link-building-outreach-drafts.md`)
- Pitch only things ByteAndBook can truthfully write about. The strongest assets are first-party: the
  CLS case study (real before/after numbers), the CI/CD checklist, the GEO self-test method, the Kindle
  formatting checklist.
- No paid placements, no link swaps, no exact-match anchor requests. A link in an author bio or a
  genuinely useful in-text reference is enough.
- A "bot-blocked" status below means my checker got HTTP 403 or 406 from a script, not that the page is
  gone. The page appeared in search results; open it in a browser before pitching.

## B. Broken-link prospects (5 pages, 6 dead links, all re-checked)

Method: fetched each page, collected outbound links, requested every one, then re-requested the failures
with a second tool. A "404" is a server answer. "Connection failed" means no server answered, which is
usually a retired domain but is worth re-checking right before sending.

| # | Page that links out | Dead link on it | Result | Our possible replacement (be honest about fit) |
|---|---|---|---|---|
| 1 | blog.hubspot.com/marketing/examples-brand-style-guides | brandguides.brandfolder.com/varonis | 404 | Not an equivalent (theirs was an example guide). Offer our article only as an extra on "what to include" |
| 2 | same page | brandguides.brandfolder.com/vystar/our-brand | 404 | Same caveat |
| 3 | keap.com/small-business-automation-blog/marketing/branding/a-simple-brand-style-guide | issuu.com/lukaszkulakowski/docs/8278452-i-love-new-york-brand-guide | 404 | Same caveat |
| 4 | same Keap page, and marq.com/blog/brand-guideline-examples/ | download.skype.com/share/blogskin/press/skype_brandbook.pdf | Connection failed | Same caveat |
| 5 | vistaprint.com/hub/best-brand-guidelines | multiadaptor.com/quiqup/ | 404 | Same caveat |

**Honest read of the yield.** Broken-link building only works when the replacement is a genuine match for
what the dead link used to say. Every dead link found here was a **brand-guide example**, and our brand
article is a how-to, not an example guide, so the fit is partial. The pitch should therefore lead with
the useful fact (the link is dead) and offer ours as optional. Pages checked in the other niches
(Kindle formatting, web fonts and Core Web Vitals, GEO resource lists) produced no verified dead links
in this batch. To widen the net: run the same script against more roundup pages as new articles land.

**Pages checked with no dead links (so do not pitch):** hidekazu-konishi.com Core Web Vitals checklist,
corewebvitals.io checklist, kindlepreneur.com book-formatting-services, redokun.com brand-guidelines
templates (one shortened link that did not resolve for a script, not counted), books.by formatting
guide, Kotobee's write-for-us page. Some pages returned no extractable external links to a script
(JavaScript-rendered), so "no dead links" for those means "none seen", not "none".

## C. Tracking

Keep one row per contact in a sheet: prospect, date sent, angle, reply, outcome, link URL if published.
